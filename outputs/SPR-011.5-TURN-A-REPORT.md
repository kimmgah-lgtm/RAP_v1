## Implementation

1. Snapshot validation and deterministic difference detection for expected and
   actual records.
2. Ownership-aware decisions: only evidence-complete, unambiguous,
   `AUTO_OWNED` local differences can become `AUTO_SAFE`.
3. Plan-before-apply recovery plans bound to Library_ID, Project_ID, expected
   snapshot hash, actual snapshot hash, decision, actions, and PlanHash.
4. Mutation-free `DryRun` mode.
5. `Fixture` apply limited to `UPSERT_LOCAL_DERIVED`; delete, merge, canonical
   selection, protected writes, and production writes are unavailable.
6. In-memory candidate verification and mandatory persisted read-back
   verification after apply.
7. SQLite audit records OperationId, scope, PlanHash, before/after hashes,
   action count, protected/destructive write counts, production state, and time.
8. Stale-plan protection rejects any changed actual snapshot before apply.
9. Idempotent operation replay returns `ALREADY_COMPLETED`; a changed PlanHash
   under the same OperationId is rejected.
10. Atomic SQLite transaction recovery verified across separate processes at
    `AFTER_STATE` and `BEFORE_COMMIT`, followed by completion and replay.
