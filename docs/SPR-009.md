## Boundary

The synthesis engine consumes explicit researcher-confirmed, project-scoped Meta Coding records. It neither creates nor overwrites SPR-007 coding and emits lineage references compatible with SPR-008 rather than redefining evidence. AI-assisted, pending, conflicting, incomplete, cross-project, unsupported, or scientifically under-specified inputs are rejected.

## Statistical implementation

- Deterministic analysis datasets retain RAP upstream identities and SHA-256 dataset hashes.
- Persistent researcher-owned specifications retain model, estimator, scope, dependency strategy, moderators, engine version, and SHA-256 configuration hashes.
- Direct effects remain distinct from derived Hedges' g values and their source group statistics.
- Direction reversal is explicit and requires confirmation; original values remain unchanged.
- Fixed-effect and DerSimonian–Laird random-effects pooling return pooled estimate, SE, 95% CI, Q, I², and tau² without scientific interpretation.
- Dependency groups require an explicit strategy; every unimplemented strategy is rejected and cannot silently fall back to independent pooling.
- Missing moderators are preserved and blocked from subgroup analysis rather than recoded. Leave-one-out sensitivity runs are persisted as reproducible child analyses, and funnel diagnostics remain factual data without interpretation.
- SQLite persistence reuses the shared Operations ledger and preserves specifications, versioned results, audit events, hashes, and lineage.
