# SPR-005 — Production Bootstrap Engine

Status: PASS  
Version: `1.0.0-alpha.5`  
Build: `20260922.001`

## Scope

SPR-005 implements ADR-0011 without changing the approved architecture. It scans normalized Zotero items through the connector boundary, verifies canonical Google Drive PDFs, assigns stable Library_ID values, upserts the Research Library Master and Notion reviews, builds a deterministic index, generates a report, and switches to Live mode only after verification.

## Operational safety

- Dry run performs no reset, backup, write, or mode transition.
- Execution requires `APPROVE_PRODUCTION_BOOTSTRAP`.
- Production Clean Reset accepts only fixed RAP test-state targets and requires its own exact approval token when called directly.
- Research assets are never supplied to the reset callback.
- A non-null backup snapshot is mandatory before writes.
- Integrity or final-verification failure prevents Live mode.
- Re-running Bootstrap reuses existing IDs and upserts existing Master/Notion records.

## Acceptance result

The isolated test harness verified initial bootstrap, second-bootstrap idempotency, Live processing, backup/reset order, zero duplicate Library_ID values, zero duplicate Notion pages, and zero research-asset deletion. No live Zotero, Google Drive, or Notion call was made by the test suite.
