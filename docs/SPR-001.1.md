# SPR-001.1 — Version and Capability Metadata

## Goal

Make platform identity and implemented capability boundaries explicit before merge without changing the established local architecture.

## Version

- Platform version: `v1.0.0-alpha.1`
- Configuration value: `1.0.0-alpha.1`
- Module manifest: `ModuleVersion = 1.0.0`, `Prerelease = alpha.1`
- Build: `20260921.001` using `YYYYMMDD.NNN`

## Capability Registry

Enabled capabilities are CloudController, LocalAgent, SQLite, Logger, and Queue. Zotero, Drive, Notion, and AIReview remain disabled and unimplemented.

The registry is configuration-backed and displayed by the health dashboard. A disabled capability is an intentional product boundary, not a health failure.
