# SPR-001 — Platform Bootstrap

## Goal

Deliver an executable, production-quality local foundation without changing the existing cloud architecture.

## Delivered

- Idempotent installer and local agent entry point
- Versioned PowerShell module with strict-mode modules
- Validated JSON configuration
- Native SQLite queue with `Operations`, `Events`, `Retry`, `History`, and `Errors`
- Daily plain-text and JSON-lines logs
- Self-test covering folders, SQLite, logger, configuration, queue, and module loading
- Console health dashboard whose aggregate status passes only when every check passes

## Exclusions

Zotero, Google Drive, Notion, migration, `Library_ID`, AI review, and cloud queue behavior are not implemented.

## Acceptance

Run `Install.ps1`, followed by `Run-Agent.ps1 -SelfTest`. Both commands must exit zero and report `PASS`. Any failed check causes a nonzero exit.
